# SPOLINK Design System

The canonical SPOLINK design system is maintained in Korean at:

`SPOLINK_디자인_시스템.md`

Use that file as the source of truth for visual tokens, typography, spacing, components, states, motion, accessibility, and implementation constraints. This pointer exists so frontend tooling and agents that search for a root `DESIGN.md` can discover the project design-system contract before writing UI code.
